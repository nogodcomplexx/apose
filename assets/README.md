# Apartmány Panorama - Asset Pipeline

Sem mužete vkládat soubory stažené z Vašeho Envato Elements úctu:
- assets/fonts/ -> stažené fonty (.woff2, .ttf, .otf)
- assets/images/ -> fotografie interiéru, exteriéru, hor
- assets/icons/ -> vektorové SVG ikony (vybavení, sauna, krb)
- assets/templates/ -> šablony nebo grafické podklady
